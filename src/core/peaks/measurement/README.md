# Inferred peak measurement

`qualpf_peak_measurement` is a Qt-free C++20 STATIC target depending on Core and
consumed by Application. Graph/coordinate import requires an explicitly aligned
background. Tabular inference returns only widths actually computed under its
existing contract. Input ordering and different d values at identical normalized
angles follow the original rules. Numerical operations retain rounding-mode
constraints.

Original Phase28M.1 qualification and product-switch records are available through
the [history index](../../../../history/README.md#recovering-historical-authority).
`tests` organizes current product/unit registration. The retired `tests/phase28m1`
is a historical entry. This maintenance relocates target definitions while
preserving measurement algorithms and qualification conclusions.
