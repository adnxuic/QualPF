# Core crystallography

Qt-free implementations for chemistry/composition, unit cells, reflections,
symmetry, scattering, structure factors and theoretical cards. Private rounding
and trigonometric providers, frozen tables and qualification records retain their
original acceptance meaning.

See [developer contracts](../../../docs/developer/README.md) for current owners and
original acceptance authorities, and the [repository layout](../../../docs/developer/repository-layout.md)
for directory changes.
