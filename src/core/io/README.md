# Core I/O

The Qt-free memory readers own Pattern, CIF syntax/semantic import and powder-CIF
parsing. Infrastructure supplies filesystem and binary32 boundaries; Application
owns product admission, provenance and import workflows. Existing parsing and
numerical contracts remain unchanged.

See [developer contracts](../../../docs/developer/README.md) for current owners and
original acceptance authorities, and the [repository layout](../../../docs/developer/repository-layout.md)
for directory changes.
