# Core numerics

Array primitives, statistics, checked conversions/NINT, integration,
interpolation, linear algebra and polynomial fitting. Eigen is a private
implementation dependency. Strict floating-point options and existing mathematical
contracts remain unchanged.

See [developer contracts](../../../docs/developer/README.md) for current owners and
original acceptance authorities, and the [repository layout](../../../docs/developer/repository-layout.md)
for directory changes.
