# Changelog

All notable changes to QualPF are documented in this file. The released entries
below retain the upstream QualX history.

Record completed features, fixes, optimizations and maintenance under Unreleased,
grouped by Added, Changed, Fixed or Removed as appropriate. Move these entries to
a dated version section when releasing. Phase numbers and separate completion
reports are no longer used for routine development.
