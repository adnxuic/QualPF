# C++ replays and compatibility comparisons

This directory retains numerical replays, snapshot copy/capacity/unknown-field
tests, and regression-comparator assertions for missing inputs, mixed tolerances
and discrete fields. Current comparison programs reside in `../reference_checks`.
Frozen references and historical snapshots remain byte-identical in `../reference`.

Old Fortran names describe provenance. Current tests compile and execute C++.
See the [test entry guide](../README.md) for configuration.
