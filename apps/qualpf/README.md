# QualPF application entry

This directory contains GUI/CLI entry points and assembly of the `qualpf`
executable. Product, test and generated resource outputs belong to the selected
`build/<configuration>` directory. Existing installation rules determine installed
locations. CLI arguments, exit behavior and the program name remain unchanged.

See the [repository layout](../../docs/developer/repository-layout.md) for
current responsibilities and [developer contracts](../../docs/developer/README.md)
for existing numerical and product authorities.
